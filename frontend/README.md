# Frontend

Nuxt 4 SSR frontend for the personal blog.

## Setup

```bash
npm install
```

## Development server

Start the application on `http://127.0.0.1:3000`:

```bash
npm run dev -- --host 127.0.0.1
```

## Quality checks

```bash
npm run format:check
npm run lint
npm run typecheck
npm run test:unit
npm run build
```
