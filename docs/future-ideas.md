# Future Ideas

These ideas are intentionally outside the first release. Recording them here does not authorize implementation.

- Full light theme using the existing semantic token architecture.
- Optional simple comments after moderation, identity, abuse prevention, and storage requirements are defined.
- Additional legal music providers through explicit adapters.
- Automatic friend-site health checks with honest status semantics and rate limits.
- A carefully profiled low-density particle canvas if CSS effects cannot meet the desired quality.
- Static export/import tooling for Markdown content and site settings.
