# 05: Choose icons for Site Identity social links

**What to build:** Let an Administrator assign recognizable icons to Site Identity social links and show them consistently wherever those links appear publicly.

**Blocked by:** None (can start immediately).

**Status:** resolved

- [x] Each social link can use a common-platform preset or a custom image uploaded or selected as a Media Asset in the existing Site Identity editor. A link with no choice, an unknown preset, or an unavailable image has a generic fallback.
- [x] Saved icon choices survive reload and appear consistently on the homepage, About page, and public footer without changing link destinations or labels. Existing social-link records remain valid. (Verified in mock and real environments; evidence is recorded below.)
- [x] Only safe media references are accepted for custom images; media management reports an active social-icon reference and prevents deletion until the link stops using it.
- [x] Links remain named and keyboard accessible; decorative icon images do not duplicate the accessible label. Invalid input and failed saves retain the unsaved draft with actionable feedback.
- [x] An authenticated icon-selection flow and desktop/mobile checks of all three public locations record actual outcomes, relevant checks, and remaining limitations before resolution.
