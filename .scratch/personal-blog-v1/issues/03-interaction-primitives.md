# 03: Interaction and form primitives

**What to build:** Deliver the accessible controls and overlays used by public and administration flows so later features share one predictable interaction language.

**Blocked by:** 01: Visual concept, tokens, and background assets.

**Status:** ready-for-agent

- [ ] Button, Input, Textarea, Select, Dialog, Sheet, Tooltip, and Dropdown support their required variants and typed public behavior.
- [ ] Keyboard navigation, focus management, dismissal, labels, disabled state, validation state, and loading state work correctly.
- [ ] Touch targets and overlay layouts remain usable on narrow mobile viewports.
- [ ] Motion uses shared tokens and honors reduced-motion preferences.
- [ ] Focused component tests assert roles, labels, events, and visible state rather than implementation details.
- [ ] Browser inspection, lint, type checks, tests, and diff review pass.
