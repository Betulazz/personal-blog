# 29: Admin Media Asset management

**What to build:** Let the Administrator upload, inspect, reuse, and safely delete local Media Assets through the administration interface.

**Blocked by:** 20: Media Asset local-storage lifecycle; 24: Admin login, shell, and dashboard.

**Status:** ready-for-agent

- [ ] Upload surfaces accepted types/limits and gives safe progress, success, validation, network, and server-error feedback.
- [ ] The media library supports useful browsing, preview, metadata, copyable resolved URL/reference, loading, and empty states.
- [ ] Spoofed type, oversize content, processing failure, missing bytes, and expired session have actionable non-destructive UI.
- [ ] Delete confirmation reports known references and partial failure without pretending metadata and bytes are synchronized.
- [ ] Keyboard, touch, image/audio preview, and narrow-screen behavior are usable.
- [ ] HTTP/Playwright tests, security cases, lint, types, storage cleanup, and diff review pass.
