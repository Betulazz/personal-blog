# 26: Admin Moment and Chatter management

**What to build:** Let the Administrator manage Moment and Chatter through distinct, efficient workflows that reflect their separate fields and editorial intent.

**Blocked by:** 17: Moment and Chatter lifecycle API; 24: Admin login, shell, and dashboard.

**Status:** ready-for-agent

- [ ] Moment management supports chronological browsing, body, optional media, location, mood, Tags, status, and deletion.
- [ ] Chatter management supports search/filtering, lead/title, body, mood, Tags, status, and deletion independently of Moment.
- [ ] Forms omit irrelevant fields instead of presenting one universal content editor.
- [ ] Loading, empty, validation, authorization, session expiry, server error, and confirmation states are complete.
- [ ] Failed operations preserve recoverable input and successful mutations invalidate only relevant data.
- [ ] HTTP/Playwright flows, keyboard/mobile checks, lint, types, and diff review pass.
