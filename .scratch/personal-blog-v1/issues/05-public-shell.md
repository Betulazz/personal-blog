# 05: Public shell, navigation, and Site Identity

**What to build:** Give visitors a complete responsive application shell with atmospheric background, navigation, footer, and configurable example Site Identity that later public pages can share.

**Blocked by:** 04: Design System gallery and visual acceptance.

**Status:** ready-for-agent

- [ ] Public layout, background layers, header/navigation, main content boundary, and footer form one coherent hierarchy.
- [ ] Navigation exposes current location and has a deliberate keyboard- and touch-friendly mobile treatment.
- [ ] Site Identity uses replaceable example content and contains no copied reference identity or copyrighted media.
- [ ] Semantic landmarks, skip navigation, focus behavior, and safe external social links work.
- [ ] Mobile and reduced-motion modes reduce nonessential background work.
- [ ] All fixed visual viewports, console output, lint, type checks, tests, and diff review pass.
