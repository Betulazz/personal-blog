# 28: Admin Music Track management

**What to build:** Let the Administrator curate and reorder the exact legal Music Tracks used by the public player and see changes reflected without code edits.

**Blocked by:** 19: Music Track configuration API; 24: Admin login, shell, and dashboard.

**Status:** ready-for-agent

- [ ] The collection displays ordering, enabled state, metadata, source strategy, artwork, and validation status clearly.
- [ ] Create/edit accepts only the supported legal source strategies and gives actionable media failure feedback.
- [ ] Reorder, enable/disable, and delete behavior updates the public playlist predictably.
- [ ] Active-player changes, empty playlist, unavailable source, session expiry, and server errors are handled safely.
- [ ] The administration UI offers no scraping, catalog search, proxy, or mirroring workflow.
- [ ] HTTP/Playwright tests, player integration checks, mobile/keyboard review, lint, types, and diff review pass.
