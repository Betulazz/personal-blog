# 09: Post discovery, taxonomy, and search

**What to build:** Let visitors discover fixture-backed Posts through listing, pagination, Category, Tag, and search experiences with durable linkable state.

**Blocked by:** 08: Homepage motion and viewport acceptance.

**Status:** ready-for-agent

- [ ] Post listing communicates title, summary, publication metadata, Category, Tags, and navigation destination clearly.
- [ ] Pagination, Category, Tag, and search state is represented in linkable navigation rather than hidden component-only state.
- [ ] Category and Tag collection pages preserve filters and recover safely from invalid or empty values.
- [ ] Loading, skeleton, empty, not-found, and error states follow the Design System.
- [ ] Fixtures match the intended public API contracts and do not force later component rewrites.
- [ ] Fixed-viewport browser checks, keyboard checks, tests, lint, types, and diff review pass.
