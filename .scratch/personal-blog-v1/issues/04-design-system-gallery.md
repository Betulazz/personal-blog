# 04: Design System gallery and visual acceptance

**What to build:** Create a browser-visible Design System gallery that proves the tokens and primitives are coherent, responsive, accessible, and ready to support product pages.

**Blocked by:** 02: Glass containers and display primitives; 03: Interaction and form primitives.

**Status:** ready-for-agent

- [ ] The gallery presents every token family and primitive, including default, hover, focus, disabled, loading, validation, open, and reduced-motion states where applicable.
- [ ] Chinese/English typography, long content, empty content, and media fallbacks are demonstrated.
- [ ] Viewport screenshots use CSS-pixel scale and are captured separately from full-page screenshots.
- [ ] The gallery is verified at 375×812, 430×932, 768×1024, 1024×768, 1440×900, and 1920×1080.
- [ ] Keyboard navigation, contrast, touch targets, overflow, blur cost, and console output pass review.
- [ ] No homepage or later business feature is implemented as part of this ticket.
