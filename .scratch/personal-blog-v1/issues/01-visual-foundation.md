# 01: Visual concept, tokens, and background assets

**What to build:** Establish the original dark visual foundation that every later screen can consume, including an approved desktop/mobile concept, semantic tokens, and production-ready responsive background assets derived from the supplied source.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The concept preserves the approved spatial, glass, glow, typography, and hierarchy direction without copying reference identity or assets.
- [ ] Semantic tokens cover color, typography, spacing, radius, shadow, glass, blur, glow, motion, breakpoints, and z-index.
- [ ] Tokens include deliberate mobile and reduced-motion behavior and remain extensible for a future theme without implementing light mode.
- [ ] The supplied background has correctly sized AVIF/WebP derivatives plus a fallback and does not require small devices to download the full source.
- [ ] Desktop and mobile concept renders are inspected in a real browser before acceptance.
- [ ] Lint, formatting, type checks, relevant tests, secret scanning, and diff review pass.
